## done

- Потолок высоты (DoD 1): `runtime/panel.lua` — `height_cap()` считает
  `player.display_resolution.height / player.display_scale * 0.8`
  (`panel.HEIGHT_SHARE`, экспортирован для тестов) и ставит
  `frame.style.maximal_height` во всех положениях, не только боковых.
  Чтобы потолок рамки доходил до содержимого, по цепочке рамка → блок →
  прокрутка помечены `vertically_squashable` + `vertically_stretchable`,
  у каждой прокрутки свой `maximal_height` как жёсткий потолок.
- Прокрутка блоков (DoD 2): «Группы» (`shm_ol_scroll_sections` — внутри
  предупреждения и таблица секций), «Отдача на этой орбите»
  (`shm_ol_scroll_now`), «Линии» (`shm_ol_scroll_lines`) — каждый в своём
  вертикальном scroll-pane. Блоки — именованные потоки
  (`shm_ol_block_sections/now/lines`); в боковом положении они тоже
  обёрнуты в потоки (раньше содержимое висело прямо на рамке).
- Сворачивание блоков (DoD 3): у каждого блока треугольник в заголовке
  (`utility/collapse`/`expand` с текстовым фолбэком, как у общей кнопки).
  Состояние — `storage.panel_block_collapsed[player_index][key]`, рядом с
  `panel_collapsed`; init/migration в `control.lua` (`on_init`,
  `on_configuration_changed`). Переживает переоткрытие окна и
  сохранение/загрузку (storage), свёрнутый блок не перестраивается и
  обновлениями per-second не трогается (`find_named` не находит
  контейнеры — `fill_now`/`fill_warnings` пропускаются).
- Строка-итог (DoD 4): свёрнутый блок — треугольник + кнопка-итог.
  Итог считается по реальному содержимому: «Отдача» — из общих с
  отрисовкой данных `now_data()` (рефактор `fill_now`: данные без GUI,
  рендер из них — итог не может разойтись с блоком); «Группы» —
  `section_rows()` по тому же условию, что рендерит `add_sections`;
  «Линии» — число участников. Клик по итогу разворачивает.
- Пустой блок линий (DoD 5): нет ни участников, ни линий у силы — блок
  сводится к одной кнопке «Линии снабжения…» без заголовка и без подписи
  «пока нет»; ключ `lines-none` удалён из всех 11 локалей. Появилась
  линия — блок полный (заголовок, прокрутка, подключение).
- Локали: 3 новых ключа (`collapsed-sections`, `collapsed-now`,
  `collapsed-lines`) во всех 11 языках; формулировки механические, без
  склонений («Giving: groups __1__, exceptions __2__») — как остальная
  локаль мода («items: __1__»), чтобы не тащить формы множественного
  числа в 11 языков. Паритет сверен скриптом: 76 ключей в разделе
  `[shm-orbital-logistics]`, множества совпадают с en у всех языков.
- Тесты (DoD 6): `tests/ingame/gui.lua` — 4 новых сценария тега gui:
  каркас при 12+ группах (потолок = доля рабочей области на нижнем,
  верхнем и боковом, обе прокрутки на месте и не выше потолка),
  «Отдача» при 12 складах со смешанными источниками (12 строк групп +
  12 исключений, блок не выталкивает панель за потолок), сворачивание
  блоков по отдельности (итоги «Отдачи» 2 группы / 1 исключение и
  «Групп» по фактическим строкам блока, клик по итогу разворачивает,
  состояние переживает переоткрытие), пустой блок линий у хаба и
  площадки и его превращение в полный после создания линии.
- Свежие предупреждения прошлого тикета сохранены: контейнеры
  `shm_ol_warnings` и `shm_ol_now` с теми же именами, per-second
  `refresh_all` находит их рекурсивно (`find_named`) внутри новых
  прокруток; ловушки источников, «не сможет отдавать платформам» и
  значок «!» — без изменений.

## left / risks

- Фактическую высоту рамки API игры не отдаёт (в этой сборке у LuaStyle
  нет `height`/`width` — обнаружено прогоном, тесты переведены на
  `maximal_height`). Потолок закреплён настройками стиля и squashable-
  цепочкой; как это выглядит глазами — не смотрено (как и в прошлых
  тикетах панели).
- Доля потолка — 0.8 рабочей области; если владельцу захочется иначе,
  это одна константа `panel.HEIGHT_SHARE`.
- Итог «Групп» считает и пустую безымянную секцию новой платформы —
  она реально рендерится строкой «Section N (no group)» (так было и до
  тикета); тест сверяет итог с числом отрендеренных строк, а не с
  константой.
- Guard сессии блокирует и `git add`/`git commit`: дифф и оба сообщения
  коммитов ниже, коммитит владелец.
