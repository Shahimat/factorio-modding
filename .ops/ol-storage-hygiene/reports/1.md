## done

- DoD 1. Утечки storage закрыты (`runtime/controller.lua`):
  - чистая функция `prune(map, alive)` — остаются только живые ключи;
  - `sweep()` — зачистка `storage.orbit`, `storage.platforms` и
    `storage.cache.hubs` по живым платформам и unit_number хабов; вызывается
    в начале `controller.pass()` и раз в круг в `controller.slice()`
    (slice == 0), где раньше чистился только `storage.orbit`;
  - `controller.migrate()` (вызывается из `on_configuration_changed`)
    подчищает те же записи сразу после обновления модов — до миграции
    состояний;
  - кеши по имени группы: `parsed` (кеш разбора меток) и
    `storage.cache.groups` чистятся `prune_groups()` раз в круг — окно
    `seen_groups` (имена групп, замеченные в `survey` за круг) покрывает
    все живые группы; запись исчезнувшей группы живёт не дольше круга
    (~1 c). Игрок удаляет секции/группы без события, которое мод слышит,
    поэтому зачистка по проходу, без тяжёлых обходов.
- DoD 2. Мёртвый код и guard:
  - `tags.places` удалён из `logic/tags.lua` (использований в коде не было —
    grep по моду: только тест); из `tests/tags.test.lua` убран assert на
    несуществующую функцию (тест «метка из выбора в панели» сохранён);
  - `read_fields` в `runtime/lines_gui.lua` не падает на nil-фрейме —
    guard `if not frame then return end` в начале функции.
- Тест: в `tests/ingame/core.lua` добавлен сценарий «зачистка storage →
  удаление платформы подчищает её записи в storage и кешах групп»: платформа
  с `[reserve]`-секцией и секцией без группы + сосед со складом; до удаления
  есть `storage.platforms[index]`, `storage.orbit[index]`,
  `storage.cache.hubs[unit]`, `storage.cache.groups['Test fuel [reserve]']`;
  после `platform.destroy()` + `controller.pass()` записей нет, живая группа
  склада не задета.
- `release_all` и K-сценарии не менялись: при выключении мода storage
  по-прежнему очищается целиком; sweep удаляет только записи несуществующих
  платформ/хабов.

  группы может дожить до границы круга (~1 c в игре). На корректность не
  влияет — кеш чисто читательный.

  правки) — стоимость не изменилась.
