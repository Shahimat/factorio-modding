# Рабочий контекст между сессиями

Короткоживущие записи, которые нужны следующей сессии и которым нет места в
слоях документации. Правила ведения — скилл `closeout`
(`.claude/skills/closeout/SKILL.md`), разбор на старте — скилл `startup`.

Разделы по приоритету (`[blocker]`, `[high]`, `[medium]`, `[low]`) появляются
только вместе с записями и удаляются с последней из них. Непустой `[blocker]`
останавливает работу: он разбирается до того, как брать что-либо ещё.

Записей нет.
