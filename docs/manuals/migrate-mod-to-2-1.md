# Перевести мод на дорожку Factorio 2.1

## Когда использовать

Когда для конкретного мода нужна вторая дорожка релизов под Factorio 2.1 —
либо потому что мод понадобился игрокам на experimental, либо в рамках общего
перехода на 2.1, когда он станет stable.

Правила дорожек — `context/conventions/factorio-version-track.yml`.

## Что требуется

- Установленный клиент Factorio 2.1 (opt-in в experimental через Steam или
  встроенный апдейтер). Ставить рядом со stable: сейв, открытый в 2.1, может
  не открыться в 2.0 — бэкапь сейвы заранее.
- Мод, уже живущий на дорожке 2.0.

## Ключевой факт

`factorio_version` указывает **ровно одну** мажорную версию. «И 2.0, и 2.1» в
одном релизе невозможно, даже если мод фактически работает в обеих. Поэтому
поддержка двух версий — это два потока релизов одного мода на портале; игра
сама выбирает последний релиз с подходящим `factorio_version`.

Так живёт Krastorio2: релизы `2.0.19` (`factorio_version: 2.0`) и
`2.1.1`…`2.1.3` (`factorio_version: 2.1`) лежат вперемешку в одном списке
релизов.

## Шаги

1. Заведи ветку под дорожку 2.1, чтобы правки не смешивались с 2.0.

2. Поменяй `factorio_version` на `"2.1"`.

3. Проверь актуальную версию experimental и прогони мод на ней:

   ```bash
   curl -fsSL https://factorio.com/api/latest-releases
   ```

4. Прогон по `test-mod-locally.md` целиком, включая
   `--check-unused-prototype-data`: переименованные или удалённые свойства
   прототипов проявляются именно там.

5. Просмотри лог на предупреждения об устаревших API — ошибки стадии данных
   и runtime уходят в `factorio-current.log`.

6. Добавь секцию в `changelog.txt` с категорией `Compatibility` или
   `Modding` — явно укажи, что релиз под Factorio 2.1.

7. Выпусти релиз по `release-mod.md`. Версия мода остаётся в своей
   нумерации, в дорожку её не кодируем.

8. Проверь, что на портале появился релиз именно с `factorio_version: 2.1`,
   а релизы дорожки 2.0 остались на месте:

   ```bash
   curl -fsS https://mods.factorio.com/api/mods/shm-<mod-key> \
     | python3 -c 'import json,sys,collections; j=json.load(sys.stdin); \
print(collections.Counter(r["info_json"]["factorio_version"] for r in j["releases"]))'
   ```

## Контекст перехода

- 2.1 — последнее крупное обновление Factorio; после него Wube переходит в
  режим поддержки (багфиксы, платформа, моддинг).
- Experimental-период 2.1 растянут специально, чтобы мод-авторы успели
  переехать.
- Миграция экосистемы уже массовая: на 2026-10-03 у 7 377 модов последний
  релиз помечен `2.0`, у 4 419 — уже `2.1`.

## Когда отказываемся от дорожки 2.0

Когда 2.1 станет stable и этого захочет автор:

1. Дорожка 2.0 замораживается — новые релизы в неё не идут, старые остаются
   доступны на портале.
2. `target.factorio_stable` в `context/project.yml` переводится на `2.1`.
3. `context/conventions/factorio-version-track.yml` упрощается до одной
   дорожки.
4. В `CHANGELOG.md` появляется строка о переходе.
5. Этот manual удаляется либо переписывается под следующую мажорную версию.
