# shm-orbital-logistics-probe

Прототип к ТЗ `specs/27102026_spec_orbital_logistics.md`, раздел 9. Проверяет,
как ванильная логика 2.1 передаёт предметы между платформами на одной
орбите и сбрасывает их на планету. Не публикуется, живёт до перехода мода к
реализации; выводы — entity `engine-space-platforms`.

## Запуск

    npm run test:ingame -- -c poc/shm-orbital-logistics-probe/factorio-test.json
    npm run check-lua -- poc/shm-orbital-logistics-probe

Тесты — наблюдения, а не утверждения: они падают только на сломанной
оснастке (опора V-00). Результат каждого — строка `[OBS] <id> …` в
`.work/ingame-stand/orbital-logistics-probe/data/factorio-current.log`:

    grep -h '\[OBS\]' .work/ingame-stand/orbital-logistics-probe/data/factorio-current.log

Платформы ставятся скриптом на орбиту Нависа, без расписания; перелёты не
нужны. Поставщик A держит 500 железных плит, получатель B запрашивает 50 с
платформ над Нависом. Отдал ли A, смотреть по его минимуму за наблюдение:
счётчик площадки в общем прогоне может зацепить груз, долетающий от
платформ прошлых тестов (они удаляются не сразу). Спорное наблюдение по
площадке перезапускается по отдельности, фильтр — имя теста:

    npm run test:ingame -- -c poc/shm-orbital-logistics-probe/factorio-test.json -- "V-06d"

## Что чем проверяется

| — | V-00, V-00b | опора: без запросов A отдаёт B за ~940 тиков; с выключенным флагом — нет |
